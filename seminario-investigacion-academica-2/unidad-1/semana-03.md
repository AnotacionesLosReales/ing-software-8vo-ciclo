# Semana 3: Herramientas de IA para la Investigación

## IA Generativa

- **Machine Learning (ML):** Subcampo de la IA que se enfoca en algoritmos que aprenden de los datos. Ejemplos: Clasificación de correos electrónicos (spam/no spam), predicción de precios de viviendas.
- **Deep Learning (DL):** Subcampo del ML que utiliza redes neuronales profundas para modelar datos complejos. Ejemplos: Reconocimiento facial, traducción automática
- **IA Generativa (GAI: Generative Artificial Intelligence):** Subcampo del DL que se enfoca en crear nuevos datos (imágenes, texto, audio). Ejemplos: Creación de imágenes realistas con DALL-E, generación de texto con GPT, composición de música con IA.
- **IA Explicable (XAI: Explanaible Artificial Intelligence):** Dominio transversal que se aplica a todos los niveles (ML, DL, IA Generativa, sistemas basados en reglas) para hacer que los modelos sean interpretables y transparentes. Ejemplos: Explicación de diagnósticos médicos generados por IA, justificación de decisiones de crédito.

## Herramientas de IA Generales

Las herramientas IA generales pueden ser usados para apoyar a la investigación, estas permiten:
- Sugiere temas de investigación
- Búsqueda y resumen de información
- Seleccionar artículos
- Identifica vacíos, limitaciones y falencias de los estudios
- Análisis y procesamiento de datos
- Redactar síntesis de artículos
- Apoya a la redacción de artículos
- Genera código de programas (desarrollo de software).

### Características destacadas

- SciSpace y Elicit son ideales para revisiones sistemáticas, ya que automatizan la extracción de datos y resúmenes.
- Consensus y Scite.ai validan la calidad de las fuentes, mostrando el consenso científico o el impacto de las citas.
- Research Rabbit y Connected Papers facilitan el mapeo visual de la literatura, útil para identificar tendencias.

## Uso de herramientas de IA para mejorar la Introducción

Para mejorar la redacción de un artículo/tesis a través de una herramienta de IA, se sugiere seguir los siguientes pasos:
- P1. Abra una herramienta de IA, previamente registrado, si usa ChatGPT que sea de preferencia pagado.
- P2. Nuevo chat. Abra una nueva ventana y use este exclusivamente para la redacción de su artículo/tesis.
- P3. Prompt de privacidad, rol y tarea.
- P4. Prompt para mejorar el contexto
- P5. Prompt para mejorar la definición del problema
- P6. Prompt para mejorar la importancia del problema
- P7. Prompt para completar referencias

### Prompt para la Privacidad

```
Eres un investigador senior experto en el tema de “tema de investigación” con PhD en “especialidad en el tema”, que apoya a la redacción de una “artículo” para una revista de alto impacto (cuartil Q1).
Todos los textos que se generen en este chat deben ser privados, no se deben compartir para evitar la similitud de la revista.
Tus respuestas deben estar escrito en un lenguaje formal, objetivo, sin redundar y escrita de manera que no sea identificada como generado por la IA por los softwares como Turnitin.
```

### Prompt para mejorar el contexto

```
El siguiente texto es el contexto sobre “tema del contexto” de la sección de introducción del artículo: TEXTO DE CONTEXTO.
```

*Nota: Para la tesis esta bien 2 párrafos, pero para el artículo es suficiente un párrafo. Pida: “Escriba su respuesta en un párrafo”*

*Recordar que en la introducción de un artículo, el primer párrafo se centra en el contexto y el segundo en el planteamiento del problema.*

### Prompt para mejorar la definición del problema

```
El siguiente texto es la definición del problema “título del problema” de la sección de introducción del artículo: TEXTO DEL PROBLEMA.
Coloque su respuesta en en un solo párrafo. Recuerde que debe ser fluido, no redundar, usar lenguaje científico y evite eliminar citas.
```

*Si la respuesta es extensa (3 párrafos), entonces eso está bien para la tesis, pero para el artículo es suficiente un párrafo. Pida: “Escriba su respuesta en un párrafo, no redunde”*

