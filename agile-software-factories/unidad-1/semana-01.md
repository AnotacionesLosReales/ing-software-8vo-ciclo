# Semana 1: Software Factory Intro

## Intro

### Agile Software Factory

Una Agile Software Factory es un modelo de desarrollo de software que utiliza metodologías ágiles para crear soluciones tecnológicas de manera eficiente y rápida. Sus beneficios son:

- **Productividad:** aumenta la eficiencia del equipo.
- **Calidad:** garantiza software de alta calidad.
- **Ahorro de Costos:** reduce costos y tiempo de desarrollo.
- **Flexibilidad:** se adapta rápidamente a cambios.
- **Innovación:** promueve la innovación continua.

### Conceptos clave en Agile Project Management

- **User Stories:** descripciones breves y simples de una funcionalidad desde la perspectiva de un usuario final.
- **Acceptance Criteria:** condiciones a tomar en cuenta para definir la completitud de una historia de usuario.
- **Product Backlog:** lista priorizada de las historias de usuario y requisitos que deben ser abordados por el equipo.
- **Sprint Backlog:** subconjunto del product backlog que el equipo se compromete a completar durante un sprint.
- **Work-items:** unidades de trabajo que pueden ser tareas, bugs o historias de usuario.
- **Estimation:** proceso de evaluar el esfuerzo necesario para completar un work-item.

### TDD, BDD y ATDD

#### Test-Driven Development (TDD)

- Desarrollo guiado por pruebas.
- Primero pensar en los datos de entrada y los datos de salida esperados para empezar a programar.
- Cambio de mentalidad.

*Beneficios*

- Escribir el código necesario para que las pruebas pasen.
- Probar la funcionalidad previa a la integración.
- Comprobar que una funcionalidad sigue trabajando de manera adecuada después de un cambio.

#### Behavior-Driven Development (BDD)

- Desarrollo guiado por el comportamiento.
- Complemento a TDD con escenarios de negocio.
- Busca un lenguaje común para unir la parte técnica con la del negocio.
- Se utiliza al momento de realizar Pruebas de Integración.

#### Acceptance Test Driven Development (ATDD)

- Discutir
- Destilar
- Desarrollar
- Demostrar
