# Semana 4: Aplicación de modelamiento de procesos

## Creación del proceso

- El proceso de desarrollo de software surge de la comunicación con el cliente.
- Comunicación transforma a requisitos mediante Design Thinking en Cliente, Deseo y Valor.
- Valor aplica a Definition Of Done.
- Backlog conformado por **HISTORIAS DE USUARIO, REQUISITOS TÉCNICOS, RIESGOS (estrategias), RETRABAJO y COSTO DE LA CALIDAD.**
- El backlog da nacimiento al proceso.
- El backlog es un acuerdo entre el dueño y el cliente donde el cliente se compromete a pagar por el desarrollo.
- Para conocer mejor el backlog, se puede empezar conociendo a un cliente (para conocer sus necesiades).
- Las tareas del backlog se planifican en el sprint backlog y se priorizan mediante puntos de historia de usuario con técnicas como Fibonacci.
- La norma ISO 12207 es una de las que se aplica para la definición del Sprint Backlog.
